WORKFORCEAI v2 — browser dashboard

1. Extract all files. Open the workforce-ai folder containing dashboard.py.
2. Double-click START_DASHBOARD.bat, or open CMD in this folder and run:
   python dashboard.py
3. Browser opens http://127.0.0.1:8501/ ; keep CMD open.
4. Select E001, click Analyse & recommend training, then Ask agent.
5. Try Draft a training request, then Ask agent. Confirm approve or reject in the queue.
6. For live mode: set your private Gemini API key and working model ID in the SAME CMD window before launching. Select Live - Gemini in the browser. Do not share or commit any key.
7. Run python -m unittest discover -s tests -v from this folder to reproduce 23 local tests.

No external dependencies. Synthetic data only. Local demo, not a hosted site.
Do not upload database files, cache folders, .env or API keys to GitHub.
Browser interactions and live API calls need verification on your computer.
